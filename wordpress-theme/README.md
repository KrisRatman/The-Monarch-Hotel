# The Monarch Hotel — WordPress Theme

Вторая версия проекта: та же вёрстка THE MONARCH, но как полноценная WordPress-тема с рабочим бэкендом, а не просто статичный HTML.

## Что добавляет эта версия

- **Тема на чистом PHP** (`header.php` / `index.php` / `footer.php` / `functions.php`) — без билдеров вроде Elementor, вся структура написана руками поверх WordPress Template Hierarchy.
- **Система заявок на бронирование** (`inc/booking.php`):
  - кастомный Custom Post Type `booking_request` вместо стороннего плагина;
  - форма на сайте отправляется через `fetch()` на `admin-ajax.php` без перезагрузки страницы;
  - серверная валидация (обязательные поля, порядок дат заезда/выезда, email), honeypot-защита от спам-ботов, CSRF-защита через WP nonce;
  - заявка сохраняется в БД и приходит уведомление администратору на email (`wp_mail`);
  - в admin-панели заявки видно списком с цветными статусами **«На рассмотрении» → «Подтверждено» / «Отклонено»** — админ принимает решение в один клик прямо из списка, без захода в каждую запись;
  - фильтр списка заявок по статусу.
- Хардненинг для продакшена: отключён XML-RPC, запрещено редактирование файлов темы/плагинов из админки, убраны заголовки, палящие версию WP, meta-description, ЧПУ (`/%postname%/`).

## Стек

- WordPress (PHP 8.4)
- MySQL
- Tailwind CSS (тот же дизайн-язык, что и в статичной версии)
- Vanilla JS (без jQuery/фреймворков) для AJAX-формы

## Запуск локально

1. Установите WordPress, подключите базу данных в `wp-config.php` (файл с реальными данными в репозиторий не включён).
2. Скопируйте эту папку в `wp-content/themes/monarch-hotel`.
3. Активируйте тему «The Monarch Hotel» в **Внешний вид → Темы**.
4. Соберите стили:

```bash
npm install
npm run build   # соберёт assets/tailwind.css
```

Заявки на бронирование появятся в admin-панели в разделе **Бронирования**.
